# GameDraw

GameDraw는 사용자가 선택한 이미지를 Windows 화면 기반 그림 게임의 캔버스에 자동으로 그려 주는 범용 데스크톱 애플리케이션입니다.

새 구현은 다음 원칙으로 시작합니다.

- 대상 게임의 프로세스·메모리·패킷·DLL을 수정하지 않는 외부 입력
- 창 상대 좌표와 게임 프로필을 통한 다중 게임 지원
- 원본 이미지 품질을 임의의 32×32·8색으로 제한하지 않는 이미지 파이프라인
- 픽셀 점, 스캔라인, 윤곽선, 면 채우기, 하이브리드 DrawingPlan
- 대상 창·캔버스·도구 상태를 검증하는 안전 실행
- One UI에서 영감을 받은 반응형 WinUI 3 데스크톱 UX

## 개발 기준

```powershell
dotnet restore GameDraw.sln
dotnet build GameDraw.sln -c Debug
dotnet test GameDraw.sln -c Debug
dotnet run --project src/GameDraw.App/GameDraw.App.csproj -c Debug -r win-x64
```

현재 브랜치는 실행 경로와 동일한 미리보기, 로컬 스마트 피사체 크롭, 외곽선→얼굴 특징→내부 경계→안전 채색 순서, 먼 이동 전용 4프레임 펜업 장벽, 최대속도용 AI 128색 통합, 슬라이딩 빠른 사용 안내를 포함한 최종 릴리스 후보입니다.

기본 사용 순서는 다음과 같습니다.

1. `이미지 선택`으로 PNG/JPG/WEBP/BMP 파일을 불러옵니다.
2. 필요하면 `스마트 피사체`로 배경 제거·피사체 크롭·인물 우선 순서를 켠 뒤 `이미지 분석`을 누릅니다. 검정 선화·클린 스트로크·최대 안전 속도는 자동 적용됩니다.
3. 캔버스 비율 프리셋을 고른 뒤 `영역 드래그`를 누르고 Roblox의 흰 그림 영역을 박스로 지정합니다.
4. `Podiums에 그리기 시작`을 누릅니다. GameDraw가 자동으로 숨고 Roblox를 활성화한 뒤 마우스 입력을 시작합니다.

실행 중 `F7`은 일시 정지/재개, `F8`은 마우스를 즉시 해제하고 중지합니다. 프로필 공유 기능은 상단 `고급 설정`에서 사용할 수 있습니다.

스마트 고속 선화는 얇은 윤곽을 노이즈 없는 중심 곡선으로 정리하고, 눈·속눈썹·겹친 머리카락처럼 굵은 암부만 원래 잉크 폭을 보존합니다. 보정 경로는 원본 잉크 안에서만 연결되고 긴 경로는 같은 좌표에서 주기적으로 펜을 떼므로 임의의 연결선이나 장시간 드래그 뭉침이 생기지 않습니다. 분석 뒤 미리보기는 실제 마우스가 실행할 경로를 그대로 표시합니다.

`원본 팔레트 256색`의 최대 속도는 가까운 색을 최대 128색으로 지각 통합해 HEX 왕복을 절반으로 줄입니다. 각 색 전환 전에는 마지막 점에서 펜 래치를 리셋하고 네 게임 프레임에 걸쳐 MouseUp을 재확인하며, 같은 색 점은 연결 구간 전체가 해당 색 영역 안일 때만 최대 12개까지 짧게 묶습니다.

모든 그림 모드는 최종 실행 전에 프린터식 순서로 정리됩니다. 각 색상 안에서 좌측 상단부터 아래로 진행하고 행마다 좌우 방향을 번갈아, 멀리 떨어진 영역으로 갑자기 점프하는 이동을 줄입니다. HEX 입력은 더블클릭과 붙여넣기 뒤 입력칸 값을 다시 복사해 확인하며, 값이 일치하지 않으면 그림을 계속하지 않습니다.

`게임 위에 띄우기`를 켜면 이미지·연결·실행 세 탭으로 구성된 컴팩트 작업창이 화면 오른쪽에 고정됩니다. `작업 초기화`는 현재 분석·캘리브레이션·그리기를 중단하고 이미지와 진행률을 지우되, 저장된 Podiums 캔버스와 도구 좌표는 유지합니다. 실행 중에는 상태창의 `중지 후 작업 초기화`도 사용할 수 있습니다.

## 릴리스 묶음 생성

전체 테스트를 거친 self-contained Windows ZIP과 SHA-256 체크섬은 다음 한 줄로 생성합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
```

실제 Podiums 최종 확인 항목과 코드 서명 범위는 [최종 릴리스 인계 문서](docs/FINAL_RELEASE.md)에 정리되어 있습니다.

## 정책과 안전

이 도구는 자동 입력을 사용하므로 대상 게임의 이용 약관과 경험별 규칙을 확인해야 합니다. anti-cheat 우회, 메모리 변조, 탐지 회피 기능은 제품 범위에 포함하지 않습니다.
